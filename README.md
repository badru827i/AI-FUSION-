# AI-FUSION

Next-generation full AI Assistant for Android.

## Current foundation

- Minimal dark Chat-first UI
- New chat and history navigation shell
- Research / Vision / Create / Files quick actions
- Chat composer designed for one-tap focus and keyboard resize
- Google Account sign-in shell using Android Credential Manager
- User-configurable Google OAuth Client ID field
- Android 7.0+ baseline (minSdk 24)
- Version 4.0.0 foundation

## Architecture direction

AI chat and tools will be connected to the Railway backend in the next development phase. Google ID tokens should be validated by the application server before being treated as authenticated sessions.
